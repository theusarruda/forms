# Portfólio — Matheus Arruda

Site de portfólio pessoal criado com HTML, CSS e JavaScript. Apresenta informações
profissionais, formação acadêmica, competências, projetos e links de contato.

## Funcionalidades

- Prévia de currículo editável, com dados salvos no navegador.
- Alternância entre tema claro e escuro, com preferência salva.
- Contador de visitas armazenado localmente no navegador.
- Layout responsivo com navegação por seções.

## Como executar

Abra `index.html` em um navegador. Não é necessário instalar dependências.
Bootstrap e a fonte Plus Jakarta Sans são carregados por CDN, então é necessária
uma conexão com a internet para esses recursos externos.

## Arquivos

- `index.html` — estrutura e conteúdo do portfólio.
- `syle.css` — estilos personalizados.
- `script.js` — interações e armazenamento local.
- `Fotodeperfil.png` — foto de perfil exibida na página.

## Tecnologias

HTML, CSS, JavaScript e Bootstrap 5.3.
